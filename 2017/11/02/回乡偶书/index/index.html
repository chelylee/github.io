回乡偶书

离别家乡岁月多，近来人事半消磨，唯有门前镜湖水，春风不改旧时波。——《回乡偶书》贺知章

最近一切都慢慢稳定下来了，时间过得可真快，转眼间回到家乡已半年有余。刚回来的前几个月一直在医院照顾我妈，住院三个多月，期间多次病危，那段日子有多难熬就不提了，幸好我们都没放弃。现在我妈已经出院四个半月，一直在老家疗养，精神、身体等各方面恢复的都很好。这一切都多亏了千佛山医院的医生，他们医术精湛、工作认真、待人热情，还勇于尝试。也正是因为千佛山的医生勇于尝试，建议我们盲试国内未上市的新药，才让我妈能够顺利出院。出院后更是多次耐心解答我们的疑问，所以，真要得了什么大病，去大医院、找专业的医生至关重要！ 为什么说医院、医生至关重要？没有对比就没有伤害，之前我妈是在山东省肿瘤医院就诊，虽然那里的医生也很认真负责，但是一旦出现疑难问题时，他们会有些犹豫不决，并且说话半遮半掩，专业方面也有些过于保守。这让病人及家属的位置非常尴尬，生死攸关之际医生的任何犹豫，都会让患者及家属不知所措。慎重是好事，但过于慎重就不一定了。 出院后我妈就一直在老家恢复，老爸在家专心照顾我妈。因为在老家的缘故，亲戚朋友、邻里街坊过来探望也方便很多，我每个月都会回去两次，送药、带我妈去医院复查，最近的复查结果都不错，虽然还多多少少有些小毛病，但大的问题能控制住就谢天谢地了。总之，一切又慢慢好起来了，加油吧。
